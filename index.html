🧠 Easy Logic Helper

A no-code mini app to check argument validity, rough soundness, and contradictions (Classical + simple First-Order Logic).

ELI5: How to use this (super simple)
  1. Classical Logic (left): Put premises line-by-line. Put conclusion. Click Check. If it says VALID, your conclusion follows from premises.
  2. Soundness: Tick the checkbox only if you think each premise is true in real life. Then if valid + checked, it says SOUND (based on your truth judgement).
  3. Debate Contradiction Finder: Put your claims and opponent claims (one per line). It looks for direct opposites like P vs !P.
  4. First-Order Logic (right): Add statements like forall x Human(x), exists x !Human(x), Mortal(Socrates), !Mortal(Socrates). Click check to find simple contradictions.
  5. If no contradiction appears, that means this tool did not find an obvious contradiction. (Not a full theorem prover.)

Allowed operators in classical formulas: ! (not), & (and), | (or), -> (if...then), <-> (iff), parentheses.

1) Classical Logic Argument Checker

2) Debate Contradiction Finder (You vs Opponent)

3) First-Order Logic (Simple Contradiction Check)

Supported simple FOL shapes: Predicate(a,b), !Predicate(a), forall x Predicate(x), forall x !Predicate(x), exists x Predicate(x), exists x !Predicate(x).
